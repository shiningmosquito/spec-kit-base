快速啟動專案

1

初始化環境

在專案根目錄下執行設定腳本，自動下載安裝 Go 環境及指定版 Hugo：

bash setup.sh
2

啟動本地開發伺服器

使用 Hugo 的本地熱重載伺服器，即時預覽網頁修改：

npm run dev

或者手動執行： ./bin/hugo server

3

產生靜態網站

編譯最終的網頁靜態檔，產出檔案會放置於 public/ 目錄：

npm run build

或者手動執行： ./bin/hugo --minify
